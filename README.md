# ReMotion

Pipeline-only code for **ReMotion: Training-Free Relational Trajectory Guidance for Multi-Subject Motion Transfer**.

This repository contains the source-inversion preprocessing and the core training-free generation pipeline. It intentionally excludes experiment orchestration, baseline implementations, evaluation code, datasets, generated videos, and model weights.

## Pipeline

1. `preprocess.py` performs DDIM inversion on a reference video and caches the noisy latents at the inversion timesteps.
2. `run.py` loads the cached latents, builds semantic relational trajectories, and optimizes the target latents while the video diffusion backbone remains frozen.
3. `pipeline_core.py` contains the core loading, guidance, and sampling logic used by `run.py`.
4. `utilities/` contains trajectory construction, relational alignment, temporal guidance, and latent initialization utilities.

## Environment

- Python 3.10+
- An NVIDIA GPU with CUDA
- PyTorch and Diffusers

```bash
pip install -r requirements.txt
```

The default backbone is `cerspense/zeroscope_v2_576w`, downloaded by Diffusers on first use. The paper configuration uses 24 frames at 576 x 320.

## Data layout

Prepare the following relative layout:

```text
data/
  frames/
    <video_name>/
      000.png
      001.png
      ...
  masks/
    <video_name>/
      background/
        000.png
        ...
      object_0/
        000.png
        ...
      object_1/
        000.png
        ...
  latents/
    <video_name>/
      noisy_latents_<timestep>.pt
      ...
```

`frames/` and `masks/` must be prepared externally. `latents/` is generated by `preprocess.py`. Mask folders follow the order declared in `mask_path` of the generation config; `background_mask_index` identifies the background entry.

`configs/run_example.yaml` uses `Couple_Runner` as a self-contained configuration example. Replace the paths, prompts, subject indices, and output directory for a new video.

## 1. Invert the reference video

Edit `configs/preprocess_example.yaml` and `configs/prompts_example.yaml`, then run:

```bash
python preprocess.py --config_path configs/preprocess_example.yaml
```

The script writes `noisy_latents_<timestep>.pt` files under `base_save_dir/<video_name>`.

## 2. Run ReMotion

```bash
python run.py --config_path configs/run_example.yaml
```

The generated video and a copy of the resolved config are written to `output_path`.

## Important configuration fields

- `data_path`: directory of reference frames.
- `mask_path`: background and subject mask directories.
- `latents_path`: directory containing the cached inversion latents.
- `source_prompt` / `target_prompt`: reference and target descriptions.
- `sparse_attention_weight`: weight of subject-balanced temporal guidance.
- `trajectory_loss_weight`, `interaction_loss_weight`, `semantic_velocity_loss_weight`: trajectory and relational terms.
- `optimization_steps`, `scale_range`, `n_timesteps`: latent optimization schedule.

`run.py` enables deterministic PyTorch settings and seeds from the config. The backbone parameters are frozen; only latent variables are optimized.

## Scope

This is a research pipeline release, not a benchmark package. Evaluation metrics, baseline reproduction scripts, experiment schedulers, and the paper's figure-generation code are deliberately not included.
